# XR Analytics — Privacy Policy

XR Analytics is a private tool used only by the owner of the YouTube channel Stories X-Ray (@StoriesXray) to read that channel's own YouTube Analytics data (views, engaged views, average view percentage) with read-only access (`yt-analytics.readonly`).

- It does not access any other user's data and is not offered to the public.
- Data is used only to evaluate the performance of the channel's own videos.
- Data is not sold, shared or transferred to third parties, and is not used for advertising.
- Access can be revoked at any time at https://myaccount.google.com/permissions.

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Contact: Stories X-Ray channel owner (contact email listed on the Google OAuth consent screen).
